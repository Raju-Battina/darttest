# UI MVC application

A starter ASP.NET Core MVC web application targeting .NET 10.

## Run locally

```powershell
dotnet run
```

Open the local URL printed by the command. The default route is `Home/Index`.

## Build

```powershell
dotnet build
```

## Structure

- `Controllers/` contains MVC controllers.
- `Models/` contains view and domain models.
- `Views/` contains Razor views and the shared layout.
- `wwwroot/` contains CSS, JavaScript, and other static assets.
